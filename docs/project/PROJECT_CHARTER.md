# N-IE Lab Project Charter

## 1. 目的

N-IE Labは、経営工学を軸に、品質、生産、データ、組織、改善の関係を学び、現場で使える形へ変換するための専門メディアである。

## 2. 永続Goal

製造業で働く若手・中堅実務者に対して、品質、生産、データ、組織のつながりを経営工学の視点から分かりやすく示し、ものづくりの仕組みと面白さを伝える。

同時に、運営者が実務課題を構造化し、品質規格、管理方法、評価設計、研修、図解、ツール等の具体的成果物へ落とし込めることを示す、信頼性の高いキャリアポートフォリオとして運用する。

既存サイト、公開済みコンテンツ、検索評価、URLを可能な限り保全しながら、保守性、表示速度、アクセシビリティ、セキュリティを重視して段階的に改善する。

## 3. メインターゲット

- 製造業で3〜10年程度働く若手・中堅実務者。
- 品質管理、品質保証、生産管理、製造技術、生産技術、研究開発、製品開発、工程管理、調達・サプライヤー管理等に携わる人。
- 担当業務を越えて、ものづくり全体を理解したい人。
- 将来的にリーダー、専門職、改善推進者を目指す人。

資格受験者も重要な読者だが、サイト全体のメインターゲットにはしない。

## 4. 読者への提供価値

- 品質、生産、データ、改善の因果関係を理解できる。
- 実務上の疑問から、関連する解説、図解、ケース、ツールへ移動できる。
- 個別手法の暗記ではなく、適用条件、判断基準、失敗要因を学べる。
- テンプレート、チェックリスト、演習、シミュレーションを利用できる。

## 5. ポートフォリオとしての役割

- 運営者の問題構造化能力と判断過程を示す。
- 根拠、制約、評価方法を明示し、結論だけにしない。
- 作成可能な成果物と相談可能な領域を具体化する。
- 品質管理、生産管理、統計、経営工学を横断する専門性を示す。
- 実績を誇張せず、匿名化したケースと再利用可能な知見を示す。

## 6. 成功条件

### 読者価値

- 資格対策だけではない、ものづくりの専門メディアとして認識できる。
- 分野間のつながりと、次に学ぶ内容が分かる。
- 解説だけでなく、図解、ケース、ツール、成果物を利用できる。

### ポートフォリオ価値

- 問題の捉え方、判断根拠、成果物、対応可能領域が分かる。
- 採用担当者や副業依頼者が相談の適合性を判断できる。

### 技術品質

- 主要URLと既存機能を維持する。
- 重複ページ、不要なJavaScript、重大なアクセシビリティ問題を増やさない。
- セキュリティを弱めず、モバイルでも利用できる。
- 可能な範囲でlint、型チェック、テスト、ビルドを通し、回帰を防ぐ。

## 7. 対象外

- 資格用語だけを並べるサイトへの変更。
- 日記型ブログを中心とする運用。
- 実績や効果の誇張。
- 必要性が明確でないCMS、データベース、認証、外部APIの導入。
- 可読性や速度を犠牲にする演出。

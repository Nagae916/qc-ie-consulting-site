# 技術士答案4型の正本運用

## 1. 目的

技術士第二次試験・経営工学部門の4答案型について、問題文の見方、考え方、書く順序、書きすぎない内容を一つの正本から案内する。答案を自動生成するのではなく、受験者が問題に合わせて論理を組み立てるための判断材料を提供する。

## 2. 正本

4答案型の共通ルールは `answer-frame-rules` を正本とする。公開画面では内部のファイル名やIDを表示せず、読者向けの日本語へ変換する。

正本が持つ主な項目は次のとおり。

- 答案型の表示名と役割
- 過去問ナビで使う安定した絞り込み値
- 既存ガイド内の参照先
- この型を使う問題
- 問題文で見る箇所と動詞
- 最初に考えること
- 答案の段階と各段階で書くこと
- 書きすぎない内容
- 100〜200字の短い例
- 関連する通常Knowledge
- 文字数・原稿用紙枚数の学習目安

## 3. 4型の役割

| 答案型 | 中心となる設問要求 | 基本の組み立て |
| --- | --- | --- |
| 必須Ⅰ | 多面的な課題、最重要課題、解決策、リスク、倫理・持続可能性 | 背景・課題から最重要課題を選び、複数解決策と実施後のリスク、倫理・持続可能性までつなぐ |
| Ⅱ-1 | 用語・手法の説明、関係、原理、使用方法 | 設問の動詞に合わせ、定義から必要な説明だけを簡潔に組み立てる |
| Ⅱ-2 | 担当者としての調査、分析、手順、調整、留意点 | 調査結果を分析・検討へつなぎ、必要数の手順と関係者調整、効果確認を書く |
| Ⅲ | 複数課題、最重要課題、選定理由、解決策、リスク対策 | 複数課題を比較し、選定理由を示して解決策と実施後のリスク対策へつなぐ |

Ⅱ-1では、長所・短所や具体例を常に要求しない。Ⅱ-2では、手順を常に3項目へ固定しない。いずれも問題文の動詞と条件を優先する。

## 4. 周辺データの責任範囲

- ワークシートテンプレート: 正本の流れに沿って、受験者が骨子を書き出すための入力項目を定義する。
- ワークシート記入例: 特定テーマで骨子をどの粒度まで具体化するかを示す。4型の一般ルールは定義しない。
- 添削教材メタ情報: 問題要約、頻出の失敗、確認観点を整理する。正本の説明を複製しない。
- 模範答案例: 完成答案を読む教材とし、唯一の正解や固定表現として扱わない。
- 過去問ナビ: 各問題に合う答案型を正本へ接続し、関連Knowledgeを探す入口とする。

## 5. 表示方針

- 答案構成ガイドのデスクトップ表とモバイルカードは同じ正本データから生成する。
- 各答案型の詳細も同じ正本データから生成し、画面幅ごとの二重記述を行わない。
- 過去問ナビの答案型名、説明、リンク先は正本から取得する。
- ワークシートの4型要約は正本から取得する。
- 既存URLと見出しアンカーを維持する。
- 内部IDやデータ名を公開画面へ表示しない。

## 6. 更新手順

1. 公式の設問要求と既存教材を確認する。
2. 4型に共通するルールの変更は正本だけに反映する。
3. ワークシート固有の入力補助が必要な場合だけテンプレートを更新する。
4. 記入例や答案例は、正本を変更する根拠ではなく、適用を確認する教材として扱う。
5. デスクトップとモバイル、過去問ナビからの遷移を確認する。
6. 既存URL、アンカー、過去問126件、公開ガイドへの影響を検証する。

## 7. 今回維持するもの

- 既存の答案型ガイドURLと見出しアンカー
- 過去問ナビのURLと126件の過去問データ
- ワークシート記入例、添削教材、模範答案例の本文
- 技術士を「学びを深める」副導線に置く情報設計
- 入力保存、答案生成、AI採点、PDF・Word出力を実装しない方針

# Editorial Charter

## 1. 目的

N-IE Labの編集活動は、製造業で働く若手・中堅実務者が、品質、生産、データ、改善のつながりを理解し、現場の判断へ使える知識を得られるようにするために行う。

資格用語の説明や個人の日記で終わらせず、実務上の問いを、根拠、判断軸、適用条件、成果物へ構造化する。あわせて、運営者が何を考え、どのような成果物へ落とし込めるかを誠実に示す。

## 2. 主な読者

- 製造業で3〜10年程度働く若手・中堅実務者。
- 品質管理、品質保証、生産管理、製造技術、研究開発等に携わる人。
- 担当業務を越えて、ものづくり全体の仕組みを理解したい人。
- 学んだ理論を、課題設定、判断、改善、標準化へつなげたい人。

資格受験者は重要な読者だが、編集判断を資格対策だけに最適化しない。

## 3. 編集上の約束

- 1コンテンツにつき、中心となる問いと主張を明確にする。
- 個別手法だけでなく、目的、入力、判断、出力、評価、学びのつながりを示す。
- 事実、解釈、提案、個人の経験を区別する。
- 一次情報、公的資料、規格、原著に近い資料を優先する。
- 引用は必要最小限とし、要約、構造化、再構成によって価値を作る。
- 適用範囲、前提、限界、更新日を可能な範囲で示す。
- 読者が次に読む、試す、使う行動を判断できるようにする。

## 4. ものづくりの面白さをどう伝えるか

ものづくりの面白さを、成功談や精神論だけで表現しない。要求が指標へ変わり、データが判断を支え、改善が標準へ残り、部門間の関係が変わる過程を示す。

現場の複雑さを単純化しすぎず、それでも読者が使えるように、構造図、判断フロー、ケース、テンプレート、ツールへ落とし込む。

## 5. ポートフォリオとしての誠実性

- 実施済み、提案、検証中、再構成事例を区別する。
- 未検証の効果を実績として表現しない。
- 機密情報、個人情報、企業を特定できる情報を公開しない。
- 背景、制約、情報収集、判断、成果物、一般化できる知見を示す。
- 読者が相談可能な領域と、対応できる成果物を判断できる具体性を持たせる。

## 6. 完了条件

公開候補は、次を満たしたときに編集完了とする。

- 中心となる問いと読者が明確である。
- 事実と意見が区別され、必要な出典が確認されている。
- 既存コンテンツとの重複が整理されている。
- N-IE Labの4テーマまたは既存の学習導線へ位置付けられている。
- Protected Defaults、既存URL、機密情報の扱いに問題がない。
- 公開後の更新条件と次の行動が分かる。

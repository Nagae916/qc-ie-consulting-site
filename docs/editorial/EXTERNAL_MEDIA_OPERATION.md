# SNS・外部メディア掲載運用

## 役割

- N-IE Labは再利用できるKnowledgeの正本とする。
- noteは学習経験、背景、問いを文章で伝える。
- XとInstagramは発見と更新通知の入口にする。
- 同じ本文を複数媒体へ複製しない。

## 手動更新

トップのnote記事は `src/data/site.ts` の `featuredExternalArticles` で最大2件を管理する。更新時は、公開ページでタイトル、URL、公開日を確認し、確認できた記事だけを登録する。見出しは「noteの記事から」とし、常に最新であることを保証しない。

SNSプロフィールは同ファイルの `socialChannels` を正本とする。プロフィールURLの変更時は、トップ、About、フッターの3箇所を個別修正せず、このデータだけを更新する。

## 確認項目

1. タイトル、URL、公開日が掲載元と一致する。
2. リンクが外部プロフィールまたは公開記事へ到達する。
3. 架空の記事、未公開記事、推測した日付を載せない。
4. 埋め込みスクリプト、タイムライン、外部APIは追加しない。
5. 更新後にPC・モバイル表示とキーボードフォーカスを確認する。

初期掲載情報は2026-11-17にnote RSSと公開プロフィールで確認した。

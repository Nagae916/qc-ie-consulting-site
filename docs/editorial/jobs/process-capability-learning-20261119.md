## 受け渡しと初見・技術レビュー

1. 調査：工程能力ページは安定性と適合の違い、[Cp・Cpk](cp-cpk-learning-20261119.md) は二つの指数の違いとし、重複する総論を避ける。
2. 制作：仮想の直径。規格9.40〜10.60 mm、平均10.30 mm、工程内標準偏差0.15 mm。規格幅1.20 mmに対して標準偏差6個分は0.90 mmだが、上限側の距離0.30 mmは標準偏差3個分0.45 mmより小さい。上限を越える裾を斜線と文字で示す。単品10.65 mmは0.05 mm超過。移動範囲平均0.1692 mmは仮定で、安定期の個別値を想定して1.128で割る。実データ・不適合率の実績とはしない。
3. 関連づけ：管理図から「安定でも規格外が出る理由」で到達し、次にCp・Cpkで同じ例を計算できる。規格値の由来は「品質規格の決め方」の冒頭で確認。戻り先として管理図を置き、推奨3件に限定。実際のリンク操作で確認した。
4. 初見役の模擬レビュー：まず短い答え、次に規格上限の縦線と右の斜線を見る。初稿では「これは時間変化の図か」「この裾の面積は実績か」を誤読し得たため、仮想の分布図で実測・時系列ではないとcaptionに明記。再読で「安定を判定するには管理図、規格外を読むにはここ」という区別と次の理由を確認。実利用者の評価ではない。
5. 技術・表示再検証：図・例・式を照合し、`node scripts/build-capability-figures.mjs --check` 成功。390px・1440pxと両幅の200%相当（CSS zoom）で図・式を確認。初回は390pxの200%で式が182px必要（表示幅163px）だった。数値と単位を本文へ移し、最終版は式内も横スクロールなし。従来の答案例は本文一致、URL・canonical・公開状態を維持。

# Cp・Cpkの制作・検証記録（2026-11-19 JST）

- 状態：レビュー待ち。対象：`knowledge.cp-cpk`、`/guides/stat/cp-cpk`。問い：ばらつきが同じで平均がずれると、CpとCpkはどう変わるか。
- 到達点：同じ規格とばらつきならCpが一定で、平均が規格中心から離れると近い側の距離が縮み、Cpkが下がることを説明し計算できる。
- 入力：既存Cp・Cpk教材と2問の演習、[工程能力の共通例](process-capability-learning-20261119.md)、[テンプレート](../LEARNING_PAGE_TEMPLATE.md)、[制作手順](../LEARNING_CONTENT_AGENT_HANDOFFS.md)、NISTの [能力指数の定義](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm)・[移動範囲による推定](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc322.htm)。既存MDX、静的図、生成用スクリプト、制作記録に限定。

## 受け渡しと検証

1. 調査：工程能力ページの「安定でも規格外」とは役割を分け、同じ仮想例の規格・ばらつきを固定し、平均だけを比べる。
2. 制作：両側規格9.40〜10.60 mm、工程内標準偏差0.15 mm。中心の平均10.00 mmでは上下とも0.60 mmの余裕、平均10.30 mmでは上限0.30 mm、下限0.90 mm。Cpは両方1.33、Cpkは1.33から0.67。式・単位・両側/片側の条件、安定性、分布の仮定、数値の丸めを照合した。移動範囲平均0.1692 mmは仮定で、1.128で割った工程内推定値を両ケースに使う。
3. 関連づけ：工程能力から「中心だけを動かすと指数がどう変わるか」で到達し、冒頭の答えで回収。分布の裾を見直すなら工程能力、時系列の安定性なら管理図、規格の由来なら品質規格へ。推奨3件。各本文を確認し、品質規格まで遷移した。
4. 初見役（模擬）：見る順序は同じ形の二つの山、上限までの距離、計算結果。初稿で「時間経過により平均が突然変わった図」とも読めたため、captionで別状態の模式図であって時間記録ではないと補足し、破線/実線の意味を明示。再読で規格幅・ばらつきが変わらないことを確認した。実利用者の評価ではない。
5. 技術・表示再検証：初回の390px・200%で横並びの式が314px必要（表示幅163px）。上下の式を分け、小さい値を選ぶ規則を本文へ。最終版は390px・1440px・両幅200%相当でページと数式に横あふれなし。SVGにJSは不要。従来の `GuideQuiz` ブロックをそのまま保持し、Enterで解答・正誤表示を確認した。公開状態・URL・canonicalは維持。

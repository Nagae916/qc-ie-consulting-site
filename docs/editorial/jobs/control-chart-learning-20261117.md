# Control Chart Learning Job 2026-11-17

## Job

- Target ID: `knowledge.control-chart`
- URL: `/guides/engineer/control-chart`
- Question: 管理図は何を見て工程の変化に気づく図なのか。
- Outcome: 個別値管理図の線と点、限界超過の意味、管理限界と規格限界の違いを説明できる。
- Input: 既存管理図Knowledge、既存管理図ツール、関連Knowledge、NIST/SEMATECH e-Handbook。

- Acceptance: 既存URL維持、仮想データ明記、固定限界、数値テスト、最大3関連Knowledge、モバイル・キーボード確認。
- Status: レビュー待ち。

## 1. 調査・分類の受け渡し

- 既存URLを正本として維持し、新規ページを作らない。
- 既存の汎用 `ControlChart` はツールページ用であり、個別値と管理限界の説明責任が異なるため教材表示へ転用しない。
- 見本は1点ずつ測る個別値管理図とし、NISTの移動範囲による式を使う。
- 前提は記述統計、併読は工程能力、適用判断は品質規格の決め方。
- 未確認を避けるため、連・偏り等の追加判定ルールは今回実装しない。

## 2. 制作の受け渡し

- 安定時12点の平均は50.00、移動範囲平均は0.20。
- 安定時の管理限界を全シナリオで固定する。
- 状態は安定、平均移動、ばらつき増大の3つ。すべて仮想データ。
- SVGは軸、単位、中心線、上下管理限界、測定点、信号を表示する。
- 信号は赤色だけでなく、ひし形と文字で区別する。
- 従来の答案例本文は保持し、実文字数に合わせて「約280字」と表示する。

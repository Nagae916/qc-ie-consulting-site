# Site and Note Content Policy

## 1. 役割分担

| 媒体 | 役割 | 主な内容 |
|---|---|---|
| note | 考え、経験、問い、背景を文章として残す | 仕事を通じた気づき、学習から得た問い、問題意識、個人としての見解 |
| N-IE Lab | 他者が再利用できるKnowledgeを残す | 定義、原理、判断軸、図解、フロー、ケース、テンプレート、ツール、出典 |
| SNS | 発見、要点、入口を届ける | 短い問い、図解、要点、更新案内、noteまたはN-IE Labへの導線 |

## 2. 同じテーマを扱うときの原則

同じテーマを扱っても、同じ本文を二重掲載しない。

- noteでは、なぜその問いを持ったか、どのように考えが変わったかを中心にする。
- N-IE Labでは、個人の経験から切り離して再利用できる定義、判断軸、フローへ再構成する。
- SNSでは、ひとつの問いまたは要点だけを示し、正本へ案内する。

全文転載ではなく、媒体ごとに読者の目的と構造を変える。同じ検索意図を持つ公開ページを複数作らない。

## 3. 事実・解釈・経験の扱い

- 事実は出典を確認し、要約して使う。
- 規格や法令は、適用範囲、版、発行主体を確認する。
- 解釈や提案は、事実と混同しない表現にする。
- 個人の経験は一般法則として断定せず、適用条件を示す。
- 引用は引用元と範囲を明示し、長文転載を避ける。

## 4. 公開場所

- note向けドラフトは `docs/editorial/drafts/` で管理し、公開ルート、Contentlayer、sitemapへ含めない。
- N-IE Lab向けKnowledgeは、既存の4テーマと検索意図に合う既存ガイド体系へ配置する。
- 新しいトップレベルのKnowledgeカテゴリやURL体系は作らない。

## 5. 相互導線

noteとN-IE Labを接続するときは、読者にとって次の理解または行動が増える場合だけリンクする。単なる相互送客を目的に、同じリンクを過剰に置かない。

外部媒体への公開、転載範囲、canonicalの扱いは公開前に個別確認する。

# 技術士二次 答案型別ワークシート運用ルール

## 1. 目的

技術士二次試験では、必須Ⅰ、Ⅱ-1、Ⅱ-2、Ⅲで求められる解答構造が異なる。
各問題を同じ型に押し込むのではなく、答案型ごとのワークシートに沿って骨子を整理する。

## 2. 必須Ⅰ型

課題抽出、最重要課題、解決策、リスク、倫理、持続可能性を一貫して整理する。
第二回添削課題の答案作成表をもとに、技術課題3つから最重要課題へつなげる。

## 3. Ⅱ-1型

専門用語・手法を、定義、特徴、長所短所、適用場面、留意点で整理する。
600字以内で要点を絞るため、詳細な背景説明よりも、使いどころと注意点を優先する。

## 4. Ⅱ-2型

担当者として、調査、分析、手順、関係者調整、留意点、効果確認を整理する。
手法名の列挙ではなく、何を対象に、どの順序で実施し、どのKPIで確認するかを明確にする。

## 5. Ⅲ型

課題解決・提案型として、複数課題、最重要課題、選定理由、解決策、リスク対策を整理する。
必須Ⅰ型と似ているが、社会的倫理の総論よりも、専門分野の制約条件と提案の妥当性を重視する。

## 6. 横展開ルール

新しい問題を追加する場合は、まず answerType を判定する。
次に、対応するワークシートに沿って骨子を作る。
その後、correction-examples と model-answer-examples に反映する。

## 7. 注意点

- 問題形式ごとの違いを維持する
- 必須ⅠとⅢを混同しない
- Ⅱ-1に過剰なリスク・倫理構造を入れない
- Ⅱ-2は手順と関係者調整を重視する
- Ⅲは最重要課題の選定理由を重視する
- 問題文にない要求を推測で追加しない

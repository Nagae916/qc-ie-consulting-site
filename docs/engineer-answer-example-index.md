## 取り込み時の注意

- 解答本文をそのまま保存しない
- 問題文・解答例は学習用に再構成する
- 答案型ごとの正本は answer-frame-rules.json に集約する
- 問題固有の設問要求・失敗例・キーワードは correction-examples.json に整理する
- 再構成した答案例だけを model-answer-examples.json に入れる

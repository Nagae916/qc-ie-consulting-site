# 技術士答案における倫理・持続可能性・コンピテンシー観点

このメモは、修習技術者向け資料の観点を、技術士第二次試験・経営工学部門の答案作成で使える学習ルールとして再構成したものです。原資料本文の転載ではなく、答案評価・答案改善に使う観点だけを整理します。

## 1. 技術者倫理で使う観点

- 公衆の安全・健康・福利の優先
- 持続可能な社会の実現
- 信用の保持
- 有能性の重視
- 真実性の確保
- 公正かつ誠実な履行
- 秘密情報の保護
- 法令等の遵守
- 相互の尊重
- 継続研さんと人材育成

## 2. 必須Ⅰ型で使う観点

- 技術課題が公益・安全・持続可能性にどう関係するか
- 解決策が環境・経済・社会に与える負の影響を低減できるか
- リスク対策が公衆の安全・福利を損なわないか
- データや評価指標を公正・透明に扱っているか
- 技術者として説明責任を果たしているか

## 3. Ⅲ型で使う観点

- 最重要課題の選定理由が、影響度・実現性・公益性に基づくか
- 解決策の副作用や新たなリスクを評価しているか
- 関係者との合意形成、情報共有、責任分担を考慮しているか
- 法令・契約・標準・規格を守る前提になっているか
- 持続可能性、働きやすさ、省エネ、CO2削減等に接続できているか

## 4. コンピテンシーとの対応

- 専門的学識：経営工学用語を正しく使う
- 問題解決：課題を明確化し、解決策を合理的に提案する
- マネジメント：人員、設備、資金、情報を適切に配分する
- 評価：成果や波及効果をKPIで評価する
- コミュニケーション：関係者に明確に説明し合意形成する
- リーダーシップ：関係者を調整し、実行を主導する
- 技術者倫理：公益、安全、公平性を確保する
- 継続研さん：新技術や制度変化に対応する

## 5. 答案での使い方

- 最後の段落だけに形式的に書かない
- 課題、解決策、リスク対策の各所に接続する
- 「安全」「環境」「公平性」「透明性」「説明責任」を具体的に書く
- 問題テーマに合わせて必要な観点だけ使う

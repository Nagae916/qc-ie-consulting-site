保存ファイルはその時点のルート `AGENTS.md` の**バイト単位のコピー**。Gitのコミット履歴も残す。今後 `AGENTS.md` を変更するときは、変更前の版が Git またはここに保存されていることを確認し、変更の狙いと元のコミットを記録する。現行ファイルを手作業で上書きせず、必ず差分をレビューする。

## 比較方法

1. 同じ実タスクまたは既存の検証用課題を固定し、作業条件（モデルと effort、Jevのバージョン、使用するskill、リポジトリのコード状態、採点基準）を記録する。
2. 変更前後で完了率、テスト合格率、手戻り、所要時間、入力・出力トークン、Jev・モデル料金を別々に記録する。記録不能な値は「未取得」とする。課金総額だけでなく、成功タスク当たりの費用を比較する。
3. 自動化した一次判定を評価する場合、確信度の閾値、上位モデルへ回した割合、誤って採用した判定、無効応答を記録する。数学・コード・安全性が関わる判定は別区分で検証する。
4. 少数の事例の差は確定的な性能改善とみなさず、条件や採点者の違いを明記する。

差分確認（基準点と現在）:

```sh
git diff --no-index docs/development/agent-baselines/AGENTS-2026-09-26.md AGENTS.md
```

復元候補の内容確認（作業ツリーは変更しない）:

```sh
git show f8162899b62052a0c57eca8a1942d123bcc0ef60:AGENTS.md
```

復元が必要な場合は、まず進行中の変更を保存し、基準点から `AGENTS.md` だけを新しい作業ブランチに戻してレビュー・再検証する。コミット全体の巻き戻しやforce pushはしない。バックアップを共有先でも確実に残すには、このブランチのGitHubへのpushが別途必要。

# 白書ファクト運用方針

## 1. 目的

技術士二次試験の答案で、白書類の背景情報や数値を適切に使えるようにする。

## 2. 対象

- ものづくり白書
- 環境白書・循環型社会白書・生物多様性白書
- 国土交通白書
- 中小企業白書
- その他、答案テーマに関連する白書

## 3. 更新方針

- 全ファクトを毎年更新しない
- updatePolicy: annual のものだけ年1回確認する
- updatePolicy: triggered のものは、教材作成時に確認する
- 数値未確認のものは valueStatus: needs-current-check とする
- 数値確認済みのものは numericValue、unit、valueYear、valueLabel、sourceOfficialUrl、sourcePageOrSection、lastChecked を持たせる
- 7〜8月に白書更新レビューを行う

## 4. 答案での使い方

- 数値は1答案に1〜2個で十分
- 数値よりも、その数値をどう課題・解決策に接続するかを重視する
- 最新確認が必要な値は、答案例に断定的に書かない
- 白書本文を長文転載しない
- 公開ページでは、要約・メタデータとして使う

## 5. ワークシートとの接続

- 必須Ⅰ型では、背景、技術課題、倫理・持続可能性に使う
- Ⅲ型では、背景・制約条件、選定理由、リスク対策に使う
- Ⅱ-1、Ⅱ-2では、必要に応じて適用場面や背景に使う

## 入力と答案の対応

| 入力する内容 | 答案で使う場所 |
|---|---|
| 問題背景 | 冒頭の背景説明 |
| 現状の問題 | 課題抽出 |
| 原因 | 課題の根拠 |
| 最重要課題 | 答案の中心 |
| 解決策 | 解決策パート |
| リスク対策 | リスクと対策 |
| 倫理・持続可能性 | 最終段落 |

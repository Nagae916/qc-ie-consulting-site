# 統計検定 データサイエンス発展の補助演習

## 1. この演習の使い方

このページは、統計検定 データサイエンス発展（DS発展）に関連する統計・データ活用の基礎を確認する補助演習です。

問題文・選択肢・解説はサイト独自の教材です。公式試験の過去問・模擬試験ではなく、全範囲を網羅していません。数理・情報・Pythonなどは、[公式出題範囲](https://www.toukei-kentei.jp/grade/ds_advanced/)と対応テキスト、公式サンプルで補ってください。

領域フィルタの「基盤」「データサイエンス」「データエンジニアリング」「価値創造」は、この演習の整理用分類です。DS発展の公式分類ではありません。

## 2. 演習の目的

用語暗記だけでなく、適切な手法選択、ケース判断、データ活用の考え方を鍛えることを目的にします。

間違えたテーマはカテゴリと skill を確認し、関連ガイドで復習してください。

## 4. 復習のポイント

- 間違えた問題は category と skill を確認する
- relatedGuide がある場合は該当ガイドに戻る
- 正解した問題でも、説明できないものは復習対象にする
- 他の選択肢がなぜ不適切かを自分の言葉で説明する

## 5. 今後の問題追加方針

- 公式出題範囲との対応を確認して、未対応の論点を補う
- 問題は独自に作成し、解説の根拠と関連ガイドを確認する
- 問題数よりも、適用条件や誤答理由を説明できることを重視する

# 統計検定 データサイエンス発展ロードマップ

## 1. このページの目的

このページは、日本統計学会公式認定の「統計検定 データサイエンス発展（DS発展）」を学ぶための地図です。データサイエンティスト協会の「データサイエンティスト検定 リテラシーレベル（DS検定★）」とは別の試験です。

DS発展の公式出題範囲と、N-IE Labの統計・品質管理ガイドをつなぎます。既存ガイドと4択演習は補助教材です。公式範囲の全項目や本番形式を網羅するものではありません。

## 2. DS発展で問われる力

2026年11月16日に公式試験案内と出題範囲表を確認しました。CBT方式で30問程度、60分、多肢選択・数値入力形式、合格水準は100点満点中60点以上、一般受験料は税込6,000円です。受験日と申込期限は会場ごとに確認してください。

| 学習領域（公式範囲を学習用にまとめたもの） | 学ぶ内容 |
|---|---|
| データ・AIの活用と倫理 | 活用事例、バイアス、個人情報、知的財産、情報セキュリティ |
| データリテラシーと統計 | 分布、標本抽出、推定・検定、相関・回帰、比較と解釈 |
| 数理基礎 | ベクトル・行列、微分積分、数列 |
| 情報とアルゴリズム | 論理演算、数値表現、分岐・繰り返し、探索・並べ替え |
| プログラミングとデータハンドリング | Pythonの基礎、CSV・JSON、データベース・SQL、クレンジング |
| データ取得 | オープンデータ、Web API、統計法の基礎 |

## 3. 学習優先順位

1. 公式出題範囲表とサンプル問題で、既習・要復習・初学に分ける
2. 統計検定2級などで既習の統計は問題で理解を確認する
3. ベクトル・行列、微分積分、アルゴリズム、Pythonを演習する
4. データ形式、SQL、前処理、オープンデータを確認する
5. データ・AIの利用目的と倫理・セキュリティを具体例で説明する
6. 時間を測った演習で、知識不足と計算・読解の負荷を分けて復習する

## 5. 反復演習の進め方

1. 4択問題を解く
2. 間違えたカテゴリと skill を確認する
3. 関連ガイドで復習する
4. もう一度解く
5. 公式範囲と照らし合わせ、この演習にない論点を対応テキストで補う

演習では、正解を覚えるだけでなく、他の選択肢がなぜ不適切かを説明できるようにします。

## 6. 4週間の学習例

以下はサイト独自の学習例です。受験月は固定せず、既習範囲と学習時間に応じて調整してください。

| 週 | 学習テーマ | 目標 |
|---|---|---|
| 第1週 | 範囲確認、統計の復習、数理基礎 | 弱点を特定し、行列・微分などの基本問題を解く |
| 第2週 | 情報、アルゴリズム、Python | 分岐・繰り返しを追い、処理結果を説明する |
| 第3週 | データハンドリング、AI・倫理・セキュリティ | データの扱い方と利用上の注意を具体例で説明する |
| 第4週 | 分野横断演習と弱点補強 | 時間内に解き、誤答の理由を説明する |

## 7. 技術士・品質管理との接続

DS発展の学習は、技術士答案のデータ活用力にもつながります。

品質管理では、データの種類、可視化、検定、モデル評価が改善活動に接続します。たとえば、品質不良の現状把握ではヒストグラムや層別を使い、改善効果の確認では検定やKPIを使います。

技術士答案では、データに基づく課題抽出、効果検証、リスク説明に活用できます。
